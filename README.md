# Рендер Blender в Google Colab

[![Открыть в Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Elguajo/Blend-to-Colab/blob/main/render_blender_in_colab.ipynb)

Готовый ноутбук для запуска рендера существующего проекта Blender в Google Colab. Он устанавливает выбранную версию Blender, принимает один файл `.blend` или ZIP-архив проекта, при необходимости включает GPU для Cycles и сохраняет результат в Google Drive.

Ноутбук **не изменяет** сцену, камеры, движок рендера или настройки качества, сохранённые в исходном `.blend`.

## Возможности

- Рендер одного кадра или всей анимации.
- Выбор точной версии Blender.
- Загрузка одного `.blend` или ZIP-архива с проектом.
- Автоматическая попытка использовать OptiX или CUDA для Cycles.
- Отдельная папка в Google Drive для каждого запуска.
- Необязательное скачивание результата на локальный компьютер.

## Быстрый старт

1. Нажмите кнопку **«Открыть в Google Colab»** выше.
2. В Colab выберите `Runtime → Change runtime type` и включите GPU, если рендерите в Cycles.
3. Выполняйте ячейки сверху вниз.
4. Когда появится диалог загрузки, выберите один `.blend` либо ZIP-архив с проектом.
5. Подтвердите доступ Colab к Google Drive, когда ноутбук попросит авторизацию.
6. Дождитесь завершения рендера. Путь к созданной папке будет выведен в последней ячейке.

> Для повторного запуска выполните ячейки загрузки, подключения Google Drive и рендера заново. Результаты предыдущих запусков не перезаписываются.

## Подготовка проекта Blender

Перед загрузкой убедитесь, что проект самодостаточен:

- Если используются внешние текстуры, HDRI, кеши симуляций или другие ресурсы, выполните в Blender `File → External Data → Pack Resources`.
- Либо загрузите ZIP-архив с `.blend` и связанными файлами, сохранив исходную структуру папок.
- В ZIP должен находиться ровно один файл `.blend`.

## Настройки

В первой ячейке ноутбука можно изменить следующие параметры:

| Параметр | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `BLENDER_VERSION` | Версия Blender для установки. Она не должна быть старее версии, в которой сохранён проект. | `'4.2.0'` |
| `ENABLE_CYCLES_GPU` | Пытаться включить GPU для сцен Cycles. | `True` |
| `RENDER_MODE` | `'ANIMATION'` — весь диапазон кадров; `'STILL'` — один кадр. | `'ANIMATION'` |
| `STILL_FRAME` | Номер кадра при `RENDER_MODE = 'STILL'`. | `1` |
| `DOWNLOAD_RESULT` | Дополнительно скачать готовый файл или ZIP на компьютер. | `False` |

Папка для результатов задаётся в ячейке подключения Drive:

```python
DRIVE_OUTPUT_DIR = Path('/content/drive/MyDrive/Blender Renders')
```

Её можно изменить на любую доступную папку вашего Google Drive.

## Результаты

Каждый запуск создаёт отдельную папку в `DRIVE_OUTPUT_DIR` с именем вида:

```text
<имя_blend-файла>_ГГГГ-ММ-ДД_ЧЧ-ММ-СС
```

Это предотвращает перезапись рендеров из предыдущих запусков. Если `DOWNLOAD_RESULT = True`, один готовый файл будет скачан напрямую, а несколько файлов — упакованы в ZIP-архив.

## GPU и Cycles

Для Cycles рекомендуется включить GPU в настройках среды Colab. Ноутбук по очереди пробует OptiX и CUDA; если подходящее GPU-устройство недоступно, Blender продолжит рендер на CPU с сохранёнными настройками проекта.

Для Eevee отдельная настройка `ENABLE_CYCLES_GPU` не требуется.

## Устранение неполадок

| Проблема | Что проверить |
| --- | --- |
| Blender не открывает файл | Укажите версию `BLENDER_VERSION`, не старее версии сохранения `.blend`. |
| Текстуры или HDRI не найдены | Упакуйте ресурсы в Blender или загрузите ZIP с сохранённой структурой папок. |
| Ноутбук сообщает, что найдено не один `.blend` | Загрузите только один `.blend` либо ZIP с единственным `.blend` внутри. |
| Cycles рендерит на CPU | Включите GPU в настройках среды Colab; доступность OptiX/CUDA зависит от выделенного Colab оборудования. |
| Результаты не появились в Drive | Убедитесь, что авторизация Google Drive была успешно завершена и у аккаунта есть место. |
